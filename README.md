# Robot Invaders

Space shooter façon Space Invaders pour Android : un robot défenseur contre des vagues
d'envahisseurs robots. Glisse ton doigt pour te déplacer, le tir est automatique.
3 vies, vagues de plus en plus rapides, record sauvegardé. Aucune dépendance externe.

## Obtenir l'APK

### Option A : GitHub, sans rien installer
1. Crée un dépôt GitHub et envoie-y tout le contenu de ce dossier (y compris `.github`).
2. Onglet **Actions** > workflow **Build APK** > attends la fin (environ 3 min).
3. Télécharge l'artefact **robot-invaders-apk** : il contient `app-debug.apk`.

### Option B : Android Studio
1. Ouvre ce dossier avec Android Studio.
2. Menu **Build > Build APK(s)**.
3. L'APK est dans `app/build/outputs/apk/debug/app-debug.apk`.

## Installer sur le téléphone
Copie l'APK sur le téléphone, ouvre-le et autorise l'installation depuis cette source.
